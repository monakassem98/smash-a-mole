⚙️ Game settings

📝 Rounds

Each round has a prompt, the correct answers students must whack, and wrong distractors that cost a heart. Put one answer per line (or separate with commas on a single line).

🔗 Student link generator

Each link contains the student's name, your rounds and a security signature. It works on any phone, tablet or PC, and nothing has to be stored on the student's device.

Your links

Some links are very long (over 2,000 characters). Use fewer or shorter rounds if a messaging app cuts them off.

📊 Results & analytics

☁️ Google Sheets sync

When a student finishes a game, the result is sent in the background to your Google Sheet through a free Google Apps Script web app.

One-time setup (about 3 minutes)

  1. Create a new Google Sheet. Open Extensions → Apps Script.
  2. Delete the sample code, paste the script below and click Save.
  3. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone.
  4. Authorize when asked, copy the Web app URL (ends in /exec) and paste it above.
  5. Press Send test row. If you edit the script later, use Deploy → Manage deployments → Edit → New version.
